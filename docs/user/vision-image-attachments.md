# Image attachments on Vision Pro

T3 Vision can attach up to eight images to a message or a new task. Open the
attachment menu to choose images from Photos or Files or take a screenshot of
the view in front of you.

Choose **Screenshot View**, then approve full-display sharing in the system
picker. T3 opens a small movable shutter window after frames are ready. Move it
away from the content you want, then choose the three- or five-second capture.
The shutter window closes before the audible countdown begins. T3 captures the
latest frame, stops sharing, and adds the image to the original composer.

Use the five-second option when you need time to return to an immersive app.
Fully immersive apps hide other apps' windows, so start that countdown before
entering the immersive space.

Screen capture includes digital app content. Physical passthrough is not
included, and an app can mark its content as unavailable for capture.
