# Image attachments on Vision Pro

T3 Vision can attach up to eight images to a message or a new task. Open the
attachment menu to choose images from Photos or Files or take a screenshot of
the view in front of you.

Choose **Screenshot View**, then approve full-display sharing in the system
picker. T3 opens a small movable shutter window after frames are ready. Move it
away from the content you want, then take the screenshot immediately or choose
the five-second countdown. The shutter window closes before capture begins. T3
captures the latest frame, stops sharing, and adds the image to the original
composer.

Use the five-second option when you need time to return to an immersive app.
Fully immersive apps hide other apps' windows, so start that countdown before
entering the immersive space.

Each draft thumbnail has an annotation control. It opens the image in a separate
window fitted to show the complete image. Pen, marker, eraser, color, stroke
width, undo, and redo controls remain visible above the canvas; **More Tools**
also requests the system PaperKit palette. Saving replaces the draft image while
keeping its place in the composer.
Enable **Annotate after capture** in the shutter window to open every new
screenshot in the annotation window automatically.

Choose **Capture Frames** when an issue only appears briefly. After approving
full-display sharing, record a five-second clip immediately or after a
five-second delay. T3 stops sharing when the clip ends and opens a frame-review
window; the temporary video is only used for review and is discarded when that
window closes.

Drag horizontally on the review timeline to inspect the clip. Slow movement
advances one frame at a time, while progressively faster movement scans at 2×,
5×, or 10×. The current rate, frame number, and timestamp stay visible. Tap the
timeline for a coarse jump, or use the previous/next controls for an exact
single-frame step. Select up to the remaining attachment limit, annotate any
selected frame (or annotate the current frame before selecting it), then choose
**Add Selected**. Only those extracted JPEG frames are added to the composer;
the video itself is not uploaded.

Screen capture includes digital app content. Physical passthrough is not
included, and an app can mark its content as unavailable for capture.
