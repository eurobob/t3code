# Image attachments on Vision Pro

T3 Vision can attach up to eight images to a message or a new task. Open the
attachment menu to choose images from Photos or Files, take a screenshot of an
app window, or capture a fully immersive view.

For a window screenshot, choose the window first. T3 then keeps that window
armed until you select **Capture Now**, start a three-second countdown, or
cancel. T3 stops sharing automatically after it takes the screenshot.

For an immersive screenshot, choose the full display and return to the
immersive app. An audible five-second countdown starts when frames are ready.
T3 captures the latest frame, stops sharing, and adds the image to the composer.

Screen capture includes digital app content. Physical passthrough is not
included, and an app can mark its content as unavailable for capture.
